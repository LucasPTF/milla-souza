# Milla Souza — Ativação SD

Página de vendas da Ativação SD, com três ângulos de campanha e página de obrigado.

## Rotas

- `/a1` — dor + nova saída
- `/a2` — verdade proibida
- `/a3` — resultado + quebra de objeção
- `/obrigado` — orientação pós-compra

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

## Produção

```bash
pnpm build
```
